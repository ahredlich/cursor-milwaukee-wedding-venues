# Indoor wedding venues near Milwaukee

Sortable tour sheet of indoor halls, lofts, barns, hotels, and clubs in Milwaukee and nearby (Waukesha, North Shore, Lake Country, Racine, Lake Geneva).

## Local

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

Serves `dist/` on `PORT` (Railway sets this). Health check: `/healthz`.
